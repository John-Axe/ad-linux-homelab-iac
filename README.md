# ad-linux-homelab-iac

Infrastructure-as-code implementation of the practice lab described in
[`it-helpdesk-sysadmin-portfolio`](https://github.com/John-Axe/it-helpdesk-sysadmin-portfolio)'s
`network-lab/topology.md`: one Windows Server AD domain controller
(AD DS + DNS + DHCP) and a small Ubuntu Server fleet, domain-joined, on a
private lab network.

Full write-up, prerequisites, usage, and verification status are in progress
in this commit series — see the final README for the complete picture.

## Status

This is the skeleton commit (LICENSE + `.gitignore` + placeholder README).
Vagrantfile, DSC configuration, Ansible playbook, and helper scripts follow
in subsequent commits.
